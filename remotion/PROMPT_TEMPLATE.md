# モーショングラフィックス依頼プロンプトテンプレート

Claude(Claude Code)にRemotionでモーショングラフィックス動画を作ってもらうときのテンプレートです。
全部埋める必要はありません。決まっている項目だけ書けば、残りはClaudeがいい感じに提案します。

---

## テンプレート(コピーして使う)

```
Remotionでモーショングラフィックス動画を作ってください。

【用途】: (例: YouTubeのオープニング / SNS告知 / ニュースダイジェストの動画版)
【尺】: (例: 10秒 / 30秒 / 音声ファイルの長さに合わせる)
【サイズ】: (例: 1920x1080(横・YouTube) / 1080x1920(縦・ショート,リール) / 1080x1080(正方形))
【伝えたい内容・テキスト】:
- タイトル: (例: てらこAIニュースダイジェスト)
- 本文・見出し: (箇条書きで。動画に出す文言をそのまま書く)
【雰囲気・トーン】: (例: 信頼感のあるニュース番組風 / ポップで楽しい / ミニマルで上品 / サイバー・近未来)
【配色】: (例: 紫系グラデーション / 白背景に黒文字+赤アクセント / ブランドカラー #667eea)
【動きのイメージ】: (例: 文字が下からスライドイン / タイプライター風に1文字ずつ /
  ズームしながらフェード / 数字がカウントアップ / グラフが伸びる)
【音】: (例: なし / このmp3をBGMに / ポッドキャスト音声に字幕を同期)
【参考】: (例: ○○のオープニングみたいな感じ / 参考URL・画像があれば)
```

---

## 記入例1: ポッドキャストの動画版(ニュース読み上げ)

```
Remotionでモーショングラフィックス動画を作ってください。

【用途】: ポッドキャスト「てらこAIニュースダイジェスト」のYouTube版
【尺】: podcast/ai-news-2026-07-16.mp3 の長さに合わせる
【サイズ】: 1920x1080
【伝えたい内容・テキスト】: 音声に合わせて、その日の見出し(ai-news-2026-07-16.htmlから抽出)を順番に表示
【雰囲気・トーン】: 落ち着いたニュース番組風。ラジオを聴きながら目でも追える感じ
【配色】: 今のNewsDigestと同じ紫系グラデーション
【動きのイメージ】: 見出しが切り替わるたびにスライドイン。画面下に音声の波形アニメーション
【音】: 上記mp3をそのまま載せる
```

## 記入例2: SNS告知用ショート動画

```
Remotionでモーショングラフィックス動画を作ってください。

【用途】: Instagramリール / YouTubeショートでの新エピソード告知
【尺】: 15秒
【サイズ】: 1080x1920(縦)
【伝えたい内容・テキスト】:
- タイトル: 今日のAIニュース
- 見出し3本(その日のトップ3)
- 最後に「毎朝配信中 / リンクはプロフィールから」
【雰囲気・トーン】: テンポよく、目を引くポップさ
【配色】: 黒背景にネオン系(シアン・マゼンタ)
【動きのイメージ】: 見出しが1本ずつドンッと出て、少しズームしながら次へ切り替わる
【音】: なし(無音でも伝わるように)
```

---

## 書き方のコツ

- **文言はそのまま書く**: 動画に出したいテキストは「いい感じの見出し」ではなく実際の文字列で。文字数で動きの設計が変わります。
- **迷ったら参考を挙げる**: 「Appleの発表会風」「NHKニュース風」のような一言が一番伝わります。
- **尺とサイズだけは決める**: この2つで構成がほぼ決まるので、最低限この2つがあると手戻りが減ります。
- **修正は部分指定で**: できあがった後は「2つ目の見出しの表示を1秒長く」「背景をもう少し暗く」のようにピンポイントで頼めばOK。コードで管理されているので何度でも正確に直せます。
